# Documentos de entrada v1.1 — referencia

Esta carpeta contiene documentos maestros y técnicos aportados por el solicitante
como **referencia** para actualizar la documentación canónica del proyecto. No
son sustitutos automáticos de los SDD, ADR ni cierres de Sprint existentes.

| Documento de entrada | Propósito | Documento canónico relacionado |

| `01_DOCUMENTO_MAESTRO_ANALISIS_REQUISITOS...` | Requisitos v1.1 | `../SDD/SDD-01`, `../SDD/SDD-04`, `../SDD/SDD-05` |

## Reglas de uso

1. Los documentos canónicos son los que viven en `../SDD/`, `../TESTING/`,
   `../DEVSECOPS/`, `../SEGURIDAD/` y los cierres `README_SPRINT_N.md`.
2. Este material se conserva **sin reemplazar** contenido existente.
3. Las propuestas se integran de forma aditiva y con estado explícito
   («propuesta», «no implementada»).
4. Las contradicciones y su resolución están registradas en
   [`../SDD/INTEGRACION_V1_1_CX_UX_AUTH.md`](../SDD/INTEGRACION_V1_1_CX_UX_AUTH.md).

> **Importante:** `../SDD/SDD-05_DISENO_API_REST_SAAS_INVERSIONES_RP.md` y
> `../SDD/ADR/ADR-01_DECISIONES_ARQUITECTONICAS.md` son documentos de entrada.
> El contrato API vigente es `../SDD/SDD-05_DISENO_API.md` y las decisiones
> vigentes son `ADR-0001` a `ADR-0003` más el registro v1.1.
